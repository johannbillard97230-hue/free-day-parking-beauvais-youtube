DOSSIER IMAGES — Free Day Parking Beauvais
==========================================

Contenu actuel (généré) :
  og-image.png    → image de partage social (Open Graph / Twitter Card)

Recommandations :
- Hero : l'illustration actuelle est un SVG vectoriel intégré.
  Pour la remplacer par de VRAIES PHOTOS du parking (aucune photo
  de banque d'images ne doit être présentée comme le parking réel) :
  1. placer le fichier ici (ex. parking-reel.webp, 1600 x 1000 px min.) ;
  2. le compresser (WebP, qualité ~80) ;
  3. remplacer le bloc <svg class="hero-svg"> dans index.html par
     <img src="assets/images/parking-reel.webp" alt="Parking couvert de
     Free Day Parking Beauvais près de l'aéroport de Beauvais"
     width="1600" height="1000" loading="eager" fetchpriority="high">.

Règles : toujours renseigner width/height, utiliser loading="lazy"
sauf pour l'image principale, et écrire des attributs alt descriptifs.
