DOSSIER DU LOGO OFFICIEL — Free Day Parking Beauvais
====================================================

Déposer ici le fichier du logo officiel, SANS le modifier :
  assets/logo/logo.svg   (idéalement : SVG vectoriel)
  ou
  assets/logo/logo.png   (PNG transparent, au moins 200 x 200 px)

Le fichier DOIT s'appeler exactement "logo.svg" (ou "logo.png"
avec adaptation du chemin dans index.html).

Le site affiche automatiquement le nom "Free Day Parking Beauvais"
en texte si le logo n'est pas encore présent (aucune erreur affichée).
